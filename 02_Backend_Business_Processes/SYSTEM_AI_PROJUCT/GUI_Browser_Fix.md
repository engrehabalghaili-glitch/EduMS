# حل مشكلة المتصفح - GUI Browser Fix

## 🚨 المشكلة:
المتصفح يتعامل مع الواجهة كمحتوى غير آمن ويمنع عرضها.

## 🔧 الحلول المقترحة:

### الحل 1: استخدام Chrome أو Firefox
1. افتح متصفح Chrome أو Firefox يدوياً
2. اذهب إلى: `http://localhost:8501`
3. إذا ظهر تحذير الأمان، اضغط على "Advanced"
4. ثم اضغط على "Proceed to localhost (unsafe)"

### الحل 2: إضافة استثناء في المتصفح
**Chrome:**
1. اذهب إلى Settings > Privacy and security
2. تحت "Insecure content"، اضغط على "Allow"
3. أعد تحميل الصفحة

**Firefox:**
1. اذهب إلى Settings > Privacy & Security
2. تحت "Security"، اضغط على "Settings"
3. ألغِ تحذيرات الأمان للـ localhost

### الحل 3: استخدام HTTP بدلاً من HTTPS
تأكد من استخدام:
```
http://localhost:8501
```
وليس:
```
https://localhost:8501
```

### الحل 4: تشغيل الخادم مع إعدادات مختلفة
```bash
python run_gui_manual.py
```
ثم اتبع التعليمات يدوياً.

## 📊 الخطوات بالتفصيل:

### الخطوة 1: تشغيل الخادم
1. افتح Command Prompt
2. انتقل إلى مجلد المشروع
3. شغل: `python run_gui_manual.py`
4. انتظر 10 ثواني

### الخطوة 2: فتح المتصفح يدوياً
1. افتح Chrome أو Firefox
2. اكتب: `http://localhost:8501`
3. اضغط Enter

### الخطوة 3: تجاوز تحذير الأمان
إذا ظهر تحذير:
1. اضغط على "Advanced"
2. اضغط على "Proceed to localhost (unsafe)"
3. ستظهر الواجهة بشكل صحيح

## 🎯 النتيجة المتوقعة:
بعد تطبيق هذه الحلول، ستظهر الواجهة الرسومية بشكل صحيح ويمكنك استخدامها لتحليل بيانات المدارس.

## 📞 إذا لم تنجح الحلول:
1. تأكد من تشغيل الخادم بشكل صحيح
2. جرب متصفحاً آخراً
3. تأكد من أن المنفذ 8501 متاح
4. أعد تشغيل الكمبيوتر إذا لزم الأمر
