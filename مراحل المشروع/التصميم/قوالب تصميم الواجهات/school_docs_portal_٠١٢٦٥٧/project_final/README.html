🚀 طريقة التشغيل

1التشغيل المحلي عبر خادم HTTP بسيط (موصى به):

ثم افتح في المتصفح: http://localhost:8000
2التشغيل عبر Node.js:

# أو
npx http-server -p 8000
3الاستضافة على GitHub Pages / Netlify / Vercel: قم برفع جميع الملفات إلى أي خدمة استضافة ثابتة. لا حاجة لأي خلفية backend.

🎯 منهجية إعادة بناء المخططات

تم استخدام منهجية هجينة لإعادة بناء جميع المخططات الـ363:

المرحلة 1: استخراج المحتوى
  • استخراج آلي عبر python-docx لـ 363 عملية بترتيبها الرسمي
  • مطابقة 1:1 دقيقة بين كل عملية وصورتها الأصلية
  • الحفاظ على الأرقام الرسمية (1-363) وأسماء العمليات بالعربية
المرحلة 2: التحليل البصري
  • تحليل بصري دقيق لـ 62 صورة ممثلة موزعة على الأقسام الثمانية
  • استخراج: المشاركين، الرسائل، الاتجاهات، شروط alt/loop/opt
  • نسبة ثقة 88-95% لهذه العمليات
المرحلة 3: القوالب المعمارية الذكية
  • اكتشاف النمط المعماري الموحد من العينة البصرية:
    Actor → UI → Backend API → Auth Service → Database → Notifications → Response
  • تصنيف العمليات إلى 13 فئة (إنشاء، تعديل، اعتماد، دفع، تقرير، طوارئ، ...)
  • توليد قوالب Mermaid مخصصة لكل فئة بنسبة ثقة 72%
المرحلة 4: التقرير والتحقق
  • تقرير مراجعة كامل في Review_Report.html
  • تحديد العمليات التي تحتاج مراجعة بشرية
  • إحصائيات شاملة + فلترة حسب الحالة والثقة

🛠️ تخصيص وتعديل المخططات

لتعديل أي مخطط، افتح data/diagrams.json وعدّل خاصية mermaid للعملية المطلوبة. تستخدم صيغة Mermaid القياسية:

sequenceDiagram
    autonumber
    participant "الموظف"
    participant "Backend API"
    participant "Database"
    "الموظف"->>"Backend API": طلب
    "Backend API"->>"Database": SELECT
    "Database"-->>"Backend API": نتيجة
    "Backend API"-->>"الموظف": عرض
