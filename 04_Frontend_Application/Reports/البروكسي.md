### 2. إصلاح غلاف البيانات (ApiResponse Wrapper)
#### [MODIFY] [base-api.service.ts](file:///H:/EduMS%20-%20front-new/EduMS-Frontend-t0-store/EduMS-Frontend-ddd/src/app/core/api/services/base-api.service.ts)
سأقوم بتعديل هذا الملف الذي يعتبر العقل المدبر لكل طلبات الـ HTTP في التطبيق. 
1. سأضيف تعريفاً لواجهة (Interface) مطابقة لـ `ApiResponse` الموجودة في الباك إند.
2. سأقوم بإضافة دالة `pipe(map(res => res.data))` في جميع الوظائف (`getAll`, `getById`, `create`, `update`, `delete`) لكي تقوم بفك الغلاف وإرجاع البيانات الصافية لبقية أجزاء التطبيق (Signals و Components) دون الحاجة لتعديل أي ملف آخر في المشروع.

```typescript
// التعريف الذي سيضاف
export interface ApiResponse<T> {
  succeeded: boolean;
  message: string;
  data: T;
  errors?: string[];
}
```
وستتغير الدوال لتقرأ الغلاف ثم ترجع البيانات فقط، مثال:
```diff
-  getAll(): Observable<T[]> {
-    return this.http.get<T[]>(this.baseUrl);
-  }
+  getAll(): Observable<T[]> {
+    return this.http.get<ApiResponse<T[]>>(this.baseUrl).pipe(
+      map(response => response.data)
+    );
+  }
```
