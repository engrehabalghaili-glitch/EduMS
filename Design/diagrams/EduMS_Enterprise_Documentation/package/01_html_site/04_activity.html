ACT-S01

Activity — احتساب درجة طالب

📐 Activity Diagram 🎯 Process 🎓 إدارة الطلاب والشؤون الأك
🎯 الغرض:التدفق المنطقي لعملية: احتساب درجة طالب.
🧩 العناصر:قرارات + تفرعات + مسارات بديلة.
flowchart TD
    Start([بداية الفصل]) --> A1[إدخال أعمال السنة]
    A1 --> A2[إدخال الشفهي]
    A2 --> A3[إدخال التحريري]
    A3 --> C1{اكتمال الدرجات؟}
    C1 -- لا --> N1[إشعار المعلم]
    N1 --> A1
    C1 -- نعم --> CALC[احتساب الدرجة النهائية]
    CALC --> V1{المجموع <= الحد الأقصى؟}
    V1 -- لا --> ERR[خطأ + مراجعة]
    ERR --> A1
    V1 -- نعم --> P1{اجتاز الحد الأدنى؟}
    P1 -- نعم --> PASS[ناجح]
    P1 -- لا --> FAIL[راسب + جدولة الدور الثاني]
    PASS --> APR[اعتماد رئيس القسم]
    FAIL --> APR
    APR --> ISS[إصدار كشف الدرجات]
    ISS --> SEND[إرسال لولي الأمر]
    SEND --> End([نهاية])

🧩 العناصر:قرارات + تفرعات + مسارات بديلة.
flowchart TD
    Start([المستخدم يكتشف عطل]) --> Report[تسجيل بلاغ + صور]
    Report --> Ticket[توليد تذكرة]
    Ticket --> Notify[إشعار الفني]
    Notify --> Assess{تقدير الفني}
    Assess -- بسيط --> InHouse[إصلاح داخلي]
    Assess -- معقد --> Approve{اعتماد مدير الصيانة}
    Approve -- نعم --> External[طلب صيانة خارجية]
    Approve -- لا --> Reject[رفض]
    External --> Vendor[تنفيذ المورد]
    Vendor --> Test1[اختبار]
    InHouse --> Test1
    Test1 --> Quality{نجح؟}
    Quality -- لا --> Repeat[إعادة]
    Repeat --> Test1
    Quality -- نعم --> Update[تحديث سجل الأصل]
    Update --> Cost[تسجيل التكلفة]
    Cost --> Return[إعادة للخدمة]
    Return --> Eval[تقييم الكفاءة]
    Eval --> Decision{معدل الفشل عالٍ؟}
    Decision -- نعم --> Replace[توصية بالاستبدال]
    Decision -- لا --> End([انتهاء])
    Replace --> End
    Reject --> End
