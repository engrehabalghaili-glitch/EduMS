خطوات النمط الأساسي

  • 1. Authorize: التحقق من JWT والدور المطلوب في الـ Controller.
  • 2. Validate: التحقق من صحة الـ DTO باستخدام FluentValidation.
  • 3. Send: تحويل الطلب إلى Command وإرساله عبر IMediator.
  • 4. Business Rules: التحقق من التفرّد أو الشروط الخاصة (unique code, existence).
  • 5. Map: تحويل الـ DTO إلى Entity عبر AutoMapper.
  • 6. Persist: إضافة/تعديل/حذف الكيان في الـ Repository (تتبّع فقط، بدون كتابة).
  • 7. Commit: IUnitOfWork.SaveChangesAsync ينفّذ الكتابة الفعلية داخل معاملة (مستخدم في 606 معالج).
