✏️ الخطوط

Cairo هو الخط الأساسي للنظام (Google Fonts). تم اختياره لوضوحه وسهولة القراءة بالعربية، مع 9 درجات سُمك.

العنوان الأكبر H1 — 36px Black
عنوان رئيسي H2 — 30px ExtraBold
عنوان فرعي H3 — 24px Bold
عنوان متوسط H4 — 20px Bold
نص الفقرة (Body) — هذا نص توضيحي يعرض شكل الخط في الحجم الطبيعي للقراءة.
النص الثانوي (Caption) — لتعليقات ومعلومات إضافية
Fira Code — للأكواد والمعرّفات: STU-001, AST-2026-00001
